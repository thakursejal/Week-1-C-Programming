# Week 1 – C Programming: Basics & Loops

This repository contains my Week 1 internship work in C Programming.

The work focuses on fundamental C programming concepts, conditional statements, loops, and a simple calculator using the switch-case statement.

## Topics Covered

- Syntax
- Variables
- Data Types
- Input/Output
- Operators
- If-Else Statements
- for loop
- while loop
- do-while loop
- Switch Case

## Assignments

### 1. Hello World

A basic C program that prints "Hello World."

File: `assignments/01_hello_world.c`

### 2. Sum of Two Numbers

A C program that takes two numbers as input and calculates their sum.

File: `assignments/02_sum_two_numbers.c`

### 3. Even or Odd

A C program that checks whether a given number is even or odd using the modulus operator and if-else statement.

File: `assignments/03_even_or_odd.c`

### 4. Fibonacci Series

A C program that prints the Fibonacci series for the given number of terms using a for loop.

File: `assignments/04_fibonacci_series.c`

## Mini Project – Simple Calculator

A simple calculator developed using the switch-case statement.

### Operations Supported

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

The program also handles division by zero.

File: `mini_project/simple_calculator.c`
